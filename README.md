# Mahdi Modern Sidebar Website 🚀

یک وب‌سایت مدرن و زیبا با طراحی Sidebar نرم و انیمیشن‌های جذاب.

## 🎨 ویژگی‌های طراحی:

- ✨ **Sidebar آنیمیشن‌دار** - حباب hover و indicator فعال که نرم حرکت می‌کنند
- 🌐 **صفحات متعدد** - خانه، درباره، خدمات، پورتفولیو، بلاگ، گالری، تماس
- 📱 **Responsive Design** - تطبیق کامل با تمام دستگاه‌ها
- 🎯 **Navigation سریع** - تغییر صفحات بدون بارگیری مجدد
- 🔐 **Login Demo** - سیستم نمایش حالت Login
- 🎭 **رنگ‌های زیبا** - طراحی با رنگ‌های آسمانی و فیروزه‌ای

## 📂 ساختار پروژه

```
mahdi-modern-sidebar/
├── index.html      # صفحه اصلی
├── style.css       # استایل‌های کامل
├── script.js       # منطق جاوااسکریپت
└── README.md       # این فایل
```

## 🚀 شروع سریع

1. Repository را Clone کنید:
```bash
git clone https://github.com/Mahdirafieam/mahdi-modern-sidebar.git
```

2. فایل index.html را در مرورگر باز کنید

3. صفحات مختلف را با کلیک بر روی آیکن‌های منو مرور کنید

## 🎮 نحوه استفاده

- **موس را روی آیکن‌ها ببرید** - حباب نرم حرکت می‌کند
- **بر روی آیکن کلیک کنید** - صفحه جدید لود می‌شود
- **بر روی تصویر پروفایل کلیک کنید** - حالت Login تغییر می‌کند

## 💻 تکنولوژی‌های استفاده‌شده

- HTML5
- CSS3 (Backdrop Filter, Gradient, Animation)
- JavaScript Vanilla
- Font Awesome Icons
